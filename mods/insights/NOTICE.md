## Antigravity transcript format

`core/antigravity.mjs` reads Antigravity's local transcripts, whose format is not documented. The field layout was
worked out with the help of [tokscale#713](https://github.com/junhoyeo/tokscale/pull/713) and
[openusage#1139](https://github.com/robinebers/openusage/pull/1139). No code was copied from either.
